# GitHub Repositories

A curated collection of GitHub repositories for AI-assisted development workflows, design tooling, and Claude Code resources.

---

## Repositories

### 1. [get-shit-done](https://github.com/gsd-build/get-shit-done)

**Category:** AI Development Workflow / Context Engineering

A lightweight meta-prompting and context engineering framework for AI-assisted development with Claude Code and similar tools. Addresses "context rot"—quality degradation as an AI fills its context window.

**Key Features:**
- Five-step development cycle: Discuss → Plan → Execute → Verify → Ship
- Multi-agent orchestration with parallel wave execution
- XML-formatted prompts for precise AI instructions
- Atomic git commits per task for clean history
- Wave-based dependency management

**Supported Runtimes:** Claude Code, OpenCode, Gemini, Copilot, and others

**Install:**
```bash
npx get-shit-done-cc@latest
```

### 2. [awesome-claude-code](https://github.com/hesreallyhim/awesome-claude-code)

**Category:** Curated Resource List / Claude Code Ecosystem

A selectively curated list of skills, agents, plugins, hooks, and tools for enhancing Claude Code workflows. Covers the full spectrum of the Claude Code ecosystem.

**Resource Categories:**
- **Agent Skills** — Domain-specific configurations (DevOps, security auditing, scientific research, full-stack dev)
- **Workflows & Knowledge Guides** — Development methodologies and documented patterns
- **Tooling** — IDE integrations (Emacs, Neovim, VS Code), usage monitors, multi-agent orchestrators
- **Status Lines** — Terminal display customizations for token usage, git status, cost tracking
- **Hooks** — Lifecycle scripts (spell-checking, desktop notifications)
- **Slash-Commands** — Quick-access commands for version control, CI/CD, documentation
- **CLAUDE.md Files** — Language/domain-specific configuration templates
- **Alternative Clients** — Other interfaces for Claude Code

### 3. [ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)

**Category:** UI/UX Design Intelligence / Claude Code Skill

An AI-powered design intelligence tool that generates professional UI/UX interfaces across multiple platforms and frameworks, integrated as a Claude Code skill.

**Key Features:**
- 67 UI styles (minimalism, glassmorphism, brutalism, neumorphism, neubrutalism, spatial UI, and more)
- 161 industry-specific reasoning rules (SaaS, fintech, healthcare, e-commerce, creative services)
- 161 color palettes aligned with product categories
- 57 font pairings with Google Fonts integration
- 13 tech stack targets: React, Next.js, Vue, Nuxt, SwiftUI, Flutter, and more
- Design system persistence for consistent cross-page implementation

**Supported Platforms:** Claude Code, Cursor, Windsurf, GitHub Copilot, and others
